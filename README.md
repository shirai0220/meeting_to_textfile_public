# Discordにおける会議の発言をすべてテキスト化するプログラム

Discordでのテキストチャット記録プログラムとAIによる高精度な音声文字起こしプログラムを組み合わせ、時系列順に統合された会議議事録を自動生成するシステムです。

ローカルPCで動作する軽量なDiscord BotとGoogle Colaboratory（クラウド）上で動作するGPU活用の文字起こしプログラムの2つのコンポーネントで構成されています。

## 背景
Discordにて打ち合わせを行っていた際、最初は「発言の意図を曲げずに記録する」という考えから発言内容をすべて手打ちで記録を取っていました。

しかしながら、この作業の負荷は非常に高く議論自体に集中できないと考え、これを自動化するシステムを作成することにしました。

また、できるかぎり私がいない状況でも実行できるようにする必要性がありましたので、Google Colaboratoryである程度動作するシステムを心がけて作成しました。

## 🌟 主な機能と特徴

### 1. リアルタイム・チャットロガー (`SimpleRecBot.py`)
- **用途**: Discordにてテキストで会議に参加している人の発言を記録するボット(のプログラム)
- **メモリ最適化設計**: メッセージをメモリに溜め込まず、受信のたびにテキストファイルへ逐次書き込む（追記保存）ストリーミング処理を行う。長時間の会議でも極めて低負荷で動作します。
- **セキュアな認証**: トークンはソースコードにハードコードせず、外部ファイル（`config.txt`）から読み込む安全な設計を採用しています。

### 2. AI音声文字起こし＆ログ統合ツール (`音声文字起こしツール_ver4.2_公開用.ipynb`)
- **用途**: `faster-whisper` (large-v3-turbo) を使用し、複数人の音声をテキストに変換しつつ、`SimpleRecBot.py`にて出力されたテキスト参加者の発言ファイルも組み込み、音声&テキストの両方の発言をそのままテキスト化し議事録としてファイルに保存します。
- **VAD (無音区間検出) とAIの幻覚フィルタリング**: 音声がない区間の推論をスキップして処理速度を向上。また、Whisper特有のハルシネーション（「ご視聴ありがとうございました」等の文脈を無視した定型文）をブラックリスト方式で自動除外します。
- **時系列の完全同期**: 録音Bot（Craig）が生成する基準時間（UNIXタイムスタンプ）を利用し、音声ファイルの発言とテキストチャットのログを1つのタイムライン上にミリ秒単位でソートして統合します。

## 🛠️ 技術的な工夫（エンジニアリング・アプローチ）
* **依存ライブラリのバージョン競合回避**
  最新の `PyAV` パッケージで発生した引数廃止による後方互換性エラー（`TypeError`）を防ぐため、インストール時にバージョン制限 (`av<19.0.0`) を明示的に指定し、安定稼働を担保しています。

* **誰でも実行できるように設計**
  誰でも実行できるようにするため、`音声文字起こしツール_ver4.2_公開用.ipynb`はgoogle Colaboratory上で使用可能としました。これにより、録音botから出力される音声ファイルをテキストファイルへ誰でも変換できます。
  
  なお、`SimpleRecBot.py`については、google Colabをサーバとして動かすのは好ましくなかったこと、そして他者が実行する際pythonなどのインストールが難しい可能性があることから、このファイルは誰でも実行できるわけではなくpythonの実行環境がある人のみが実行できるようになっています。
  しかしながら、会議参加者の大半は音声の参加者のため、`SimpleRecBot.py`の重要度は高くはありません。

## 🚀 使い方（ワークフロー）

本システムは、**ローカル環境（PC）**でのチャット記録と、**クラウド環境（Google Drive / Colab）**での音声解析を連携させて使用します。

### Step 1. Discord Botの準備と実行（ローカルPC）
1. 本リポジトリをローカルPCにダウンロードします。
2. `SimpleRecBot.py` と同じ階層に `config.txt` を作成し、Discord Botのトークンを1行だけ記述します。
3. コマンドプロンプトやターミナルでBotを起動します。
   ```bash
   python SimpleRecBot.py
   ```
4. Discord上で `!start` コマンドを送信すると記録が開始され、自動作成される `meeting_data` フォルダ内に `chat_log_YYYYMMDD.txt` が生成されます。会議が終わったら `!finish` で記録を終了します。

※なお、このreadme内では、Discordへのbot導入方法などは説明しません。

※また、このStep1は実行せずとも以降のStepは実行可能(テキスト参加者の発言内容が議事録に反映されなくなる)

### Step 2. 音声データの取得（Discord）
会議中、Discordの録音ボット（Craig）を併用して音声を録音し、会議終了後に音声ファイル一式（FLAC形式）をダウンロードしておきます。

### Step 3. Google Driveへのデータ集約（クラウド）
Google Driveのマイドライブ内に作業用フォルダ（例：`YourMeetingFolder/Data`）を作成し、以下の2つをアップロードします。
1. Step 1で生成したテキストログ (`chat_log_*.txt`)
2. Step 2で取得した音声データ (`*.zip` など)

### Step 4. 議事録の自動生成（Google Colab）
1. 本リポジトリの `音声文字起こしツール_ver4.2_公開用.ipynb` をGoogle Colaboratoryで開きます。
2. コード内の `DRIVE_FOLDER` のパスを、Step 3で作成したGoogle Driveのフォルダパスに変更します。
3. （任意）`USER_NAME_MAPPING` を編集し、Discordのアカウント名を表示名（Aさん など）に変換する設定を行います。
4. 全てのセルを上から順に実行します。処理が完了すると、対象フォルダの親ディレクトリに `Meetingkaigiroku/merged_minutes_YYYYMMDD.txt` として完成した統合議事録が出力されます。

## 今後の展望
現在は、予算の都合上SimpleRecBot.pyは個人のPCで実行するようになっており、だれでも実行できるわけではありません。
無料(もしくは低価格)で利用できるサーバを検討し、音声による参加者の発言もテキストによる参加者の発言もの両方とも議事録へ反映できるようにしたいです。
